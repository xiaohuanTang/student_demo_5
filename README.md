## 项目简介

基于SpringBoot+MySQL实现学生成绩管理系统，完成学生、课程、成绩信息管理与成绩统计分析。

## 实现功能

1. 配置SpringBoot项目与MySQL数据库连接，完成后端基础环境搭建
2. 使用Navicat创建学生表、课程表、成绩表，并初始化测试数据
3. 实现学生信息、课程信息、成绩信息的增删改查
4. 编写SQL语句，实现成绩查询、平均分、最高分、最低分等统计
5. 提供前端页面，支持浏览器访问学生成绩管理功能

## 启动

配置数据库用户名和密码后启动项目，先执行`sql/schema.sql`和`sql/data.sql`初始化数据库，访问`http://localhost:8080`进入学生成绩管理系统。
